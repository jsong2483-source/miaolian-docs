# 妙恋畅语 · 产品文档

产品文档、交互原型、评审记录与版本存档。客户端代码在另一个仓库：[miaolian-app](https://github.com/jsong2483-source/miaolian-app)。

## 目录

```text
first/
├── 01-文档/        项目书、产品重建总计划、评审记录、工程说明、上线规划
├── 02-原型/        可交互 HTML 原型与视觉稿
├── 03-版本存档/    冻结快照，只读，按 vX.Y-日期-主题 分目录
├── 04-评测发放/    评测表与回收记录
├── 05-截图/        视觉回归基线
├── 99-归档/        废弃但留档的方案
└── CHANGELOG.md    唯一的版本变更权威记录
```

## 版本规则

- 根目录文件是**工作副本**，可以继续改。
- 每次改完，复制一份到 `03-版本存档/vX.Y-YYYY-MM-DD-一句话主题/`，把存档设为只读，再在 `CHANGELOG.md` 补一条。
- **冻结版本只增不改。** 要回到旧版，从存档复制出来另存，不反向覆盖工作副本。
- 工作副本的文件名必须与真实版本号一致；存档内文件名与工作副本完全同名。
- 文件名格式：`版次-内容-vX.Y.扩展名`。

详细规则的正文在 [CHANGELOG.md](CHANGELOG.md)。
