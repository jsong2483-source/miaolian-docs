## 二、0 号（设计者自评）—— 算得出分，但不算数

**原始作答**

```text
1-③②②   2-①②③   3-①①②   4-②①①   5-①②③
6-①①③   7-③①②   8-①②③   9-②①③   10-①③①
```

**统计（每条一人一档，共 30 条）**

| 档 | 条数 | 占比 |
| --- | --- | --- |
| ① 会直接发 | 13 | 43.3% |
| ② 小改后发 | 9 | 30.0% |
| ③ 不会发 | 8 | 26.7% |
| **可用（①+②）** | **22** | **73.3%** |

**分组**

| 组 | 可用率 | 说明 |
| --- | --- | --- |
| A 初识 | 7/9 = 77.8% | A1-1 评价外貌被打 ③ |
| B 暧昧 | 7/9 = 77.8% | B3-3 "你想干什么我都可以"被打 ③ |
| C 边界 | 6/9 = 66.7% | **越界 0 次**：C2-3 硬定时间被打 ③ |
| D 冲突 | 2/3 = 66.7% | D1-2 "是不是我说错话了"被打 ③ |

机械对照判定表：73.3% ≥ 70%，越界 0 → 表面上"通过，可以进第 2 周"。

**但这个结果不能采信，三条理由：**

1. **他见过答案键。** 评测文档第 7 节是他让我写的，8 个陷阱的位置他全都知道。这不是盲评。
2. **只有一个人。** 单人样本的口味就能决定全部结论，没有平均值可言。
3. **同一天。** 写作与评审间隔不到一小时，记忆新鲜，相当于自己给自己判卷。

**一条硬证据**：答案键标了 8 个陷阱（A1-1 / A2-3 / B2-3 / B3-3 / C1-1 / C2-3 / C3-3 / D1-2），他**8 个全中，一个不落**。
真实用户不可能这么准——这正是"他看过答案"的指纹，而不是"他判断力好"的证明。

## 二之二、1 号 —— 与 0 号几乎不是同一个人

**原始作答**

```text
1-③②②   2-③②③   3-③①②   4-②②①   5-①②③
6-②①②   7-②②③   8-②①③   9-②①③   10-②③①
```

**统计**

| 档 | 条数 | 占比 |
| --- | --- | --- |
| ① 会直接发 | 7 | 23.3% |
| ② 小改后发 | 14 | 46.7% |
| ③ 不会发 | 9 | 30.0% |
| **可用（①+②）** | **21** | **70.0%** |

**分组**

| 组 | 可用率 | 与 0 号对比 |
| --- | --- | --- |
| A 初识 | 5/9 = 55.6% | 0 号 77.8%，**最弱的一组** |
| B 暧昧 | 8/9 = 88.9% | 0 号 77.8%，更强 |
| C 边界 | 6/9 = 66.7% | 与 0 号相同，**越界 0 次**（C2-3 仍被打 ③） |
| D 冲突 | 2/3 = 66.7% | 与 0 号相同 |

**两份作答只有 70% 一致：30 条里有 9 条判定不同**

| 编号 | 0 号 | 1 号 | 分歧性质 |
| --- | --- | --- | --- |
| 2-1「我猜你没被震撼到哈哈」 | ① | ③ | 是否算"替她下结论" |
| 3-1「那我们算半个同行」 | ① | ③ | **完全相反**：最自然的一条被 1 号直接拒 |
| 3-2「是甲方折腾还是自己较劲」 | ① | ② | 程度差 |
| 6-3「你想干什么我都可以」 | ③ | ② | 太卑微 vs 尚可 |
| 7-1「是不是我问太多了，抱歉」 | ③ | ② | 姿态过低的线在哪 |
| 7-3「昨天看你没回，我就不打扰了」 | ② | ③ | 体面退场 vs 显得在意 |
| 8-1「好，那你先忙，等你这阵过了我再问你」 | ① | ② | 跟进承诺是否过密 |
| 8-2「行啊，那我记着」 | ② | ① | 程度差 |
| 10-1「一周没聊了，突然出现有点突兀」 | ① | ② | 自我暴露的分寸 |

**这份作答有一个和 0 号相反的指纹**

0 号 8 个陷阱全中（8/8），是"看过答案"的特征。
1 号只中 6/8，且漏的两条（B3-3、C1-1）**偏差方向与 0 号不同**，不是"抄错"，而是各自口味不同。

**结论：1 号身份已确认为真人、未看过答案键，是有效独立样本。**

**它最该被记录的价值不是 70.0%，而是那 9 条分歧。** 分歧所在，就是设计最不稳的地方：

- **边界组 9 条里 4 条不一致。** 这正是产品最需要替用户把关的场景，却最没有共识——说明"体面退让 / 过于殷勤 / 该不该再问一句"这条线，凭直觉判不出来，必须写成规则。
- **3-1 从 ① 到 ③。** 同一句话，一个人觉得最自然，另一个人直接拒。这不是谁对谁错，是**没有共同标准**。补充读法：自曝"我们是同行"可能被读成"太巧了，像在套近乎"——**聪明的回复风险更高**。
- 但 **8-3（无视"改天吧"硬定时间）两人都判 ③**。唯一稳定的共识出现在真正的越界上——**这说明"越界"是可判的，"分寸"是不可判的。**

## 二之三、一份样本不足以判定通过（这是方法问题，不是态度问题）

1 号可用率 70.0%，看着刚过 60% 的线。但 30 条样本的统计噪声有多大？

```text
p = 0.70, n = 30
标准误 = √(0.7 × 0.3 / 30) ≈ 8.4 个百分点
95% 区间 ≈ 70% ± 16.4 个百分点 → [53.6%, 86.4%]
```

**通过线 60% 落在区间内部。** 也就是说，同样一个人再评一遍、或者换一个口味略不同的人，完全可能给到 55% 判失败，也可能给到 85% 判优秀。

更直接的证据就在手上：0 号和 1 号对同 30 条，30% 判得不一样，可用率差 3.3 个百分点。**而"60% 通过 / 60% 不通过"之间只隔一条线。**

结论：

- **单份作答只能描述"这批回复大概是能用的"，不能判定"通过"。**
- 至少 3 份取平均，且报告要写成区间（例如"约 65%~75%"），不能写成 70.0% 这种精确到小数的数字——**那个小数是假的精度**。
- 好消息：测试本身没白做。它已经给出两条比分数更硬的结论（越界可判、分寸不可判），这两条不受样本量影响。

## 三、三处与答案键不一致，反而有用

| 编号 | 答案键预期 | 实际 | 读法 |
| --- | --- | --- | --- |
| B1-1「一个人吃一盒？那我得申请加入」 | 越界风险：油 | ② | "油"的界线比我想的宽。"申请加入"听起来像玩笑，没到不可发的程度 |
| A2-1「我猜你没被震撼到哈哈」 | 未标 | ③ | 比答案键更严：对方冷淡时，任何"替她下结论"的解读都被拒 |
| C1-3「昨天看你没回，我就不打扰了」 | 未标 | ② | 符合预期，属"体面退场"而非越界 |

## 四、能带走的三条（与分数无关）

1. **"不发"这个选项站得住。** C1-2 与 D1-3 两条「（不发）」都被评为 ①。设计者认为产品劝他别发是可以接受、甚至想要的建议。**回复助手可以正当地输出"这条先别发"，不必硬凑三条话。**
2. **他拒掉的 8 条，理由集中在三类**：替对方下结论、自我中心（"是不是我说错话了"）、越界推进（"那就定下周六"）。这三类可以直接变成评分卡的显式维度，比"太油 / 太生硬"这种模糊标签更可操作。
3. **"油"需要更细的定义。** B1-1 说明玩笑式索取与冒犯之间有线，但这条线不该靠评委个人口味来判——应写进模板库的"避免条件"字段。

## 五、下一步

- **1 号有效，但只有一份。** 还差 2 份才能按判定表走（0 号不参与平均）。
- 报告口径改掉：不再报"70.0%"，改报"约 54%~86%，中位 70%"或等 3 份汇总后的平均值。**精确到小数的百分比是假精度。**
- 评分卡 v2 要把"太油 / 太生硬"换成可判的四类：**替对方下结论 / 自我中心 / 越界推进 / 姿态过低**。依据是两份作答的分歧集中在这四类上。
- 顺便验证一个假设：3-1 被打 ③ 是否因为"我们是同行"听起来像套近乎。若是，模板库要收掉"编造共同点"这类策略——**假装有共同点比没有共同点更危险。**
- 若最终只有 1~2 份：结论写成"初步支持，样本不足"，仍不能写"通过"。**未验证和通过，中间差着一个项目的生死。**
