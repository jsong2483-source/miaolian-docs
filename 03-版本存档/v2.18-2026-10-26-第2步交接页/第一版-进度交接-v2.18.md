## 二、第 2 步要做的事

**目标一句话：让 12 屏的数据来自同一处，而不是各读各的写死常量。**

### 现在真实存在的问题

1. `data.dart` 里 `Person` 是 `const` 定义的，**编译期常量，运行时没法增删**。
2. `state.dart` 里有 `_rowsMode`、`ocrRows` 这种"按普通/边界模式换一套数据"的临时代码，把数据和界面状态混在一起。
3. `home.dart` 里有一张 `_subs` map，写死了「暧昧升温 · 今天分析过」「熟悉建立 · 3 天前」——这属于数据，不该在界面文件里。
4. `panel.dart`、`analysis.dart`、`reply.dart` 里各自写 `p.id == 'demo'` 来判断"这是不是边界场景"。同一个判断散在三处，加第三个人就会漏。
5. 新建对象表单不落库，点保存只是跳回首页。

### 建议的动作顺序

1. `Person` 去 `const`，改成普通 model；`data.dart` 改名成"演示数据"，作为 repository 的初值。
2. 加一个 `PeopleRepository` 接口（现在只写内存实现，第 4 步再换 sqlite）。方法先只四个：`all()` / `byId()` / `upsert()` / `remove()`。
3. `AppState` 改成通过 repository 读写，删掉 `_rowsMode`、`ocrRows` 这类临时字段。
4. `p.id == 'demo'` 全部换成一个 model 字段（比如 `Person.isBoundary`）。**改完 grep 一遍确认没有残留。**
5. 新建对象表单真的 `upsert` 进 repository，首页和面板都能看到它。
6. 把 `home.dart` 的 `_subs` 挪进 model。

### 验收标准

- 点首页对象卡进面板，两处显示的是同一份数据（改 model 里一个数字，两处一起变）。
- 新建一个对象，首页列表、面板顶部 chips、对象数据三处都能看到。
- `dart analyze` 零问题，`flutter build web --release` 通过。
- **12 屏的界面一个字都不许变**——这是重构，不是改设计。

## 四、环境上的三个坑（都是实测，别再试错）

1. `flutter analyze` 在中文路径下会让 analysis server 崩（exit 255）。**一律用 `dart analyze`。**
2. `flutter run -d edge` / `-d web-server` 在**我的执行环境**里跑不了——Flutter 要调 `reg.exe` 查 Edge 版本，而 `reg.exe` 在安全中心黑名单里。**立项人自己的终端不受影响。**
   我的替代做法：`flutter build web --release` → `python -m http.server` 起 `build/web` → 截图自查。截图命令见下。
3. `cdn.jsdelivr.net` 在本机 TLS 握手失败；`fonts.googleapis.com` / `gstatic.com` 可通。pip 装包：tuna 镜像直接 `pip install` 会报 "versions: none"，但 **curl 下 wheel 再 `pip install --no-index 本地.whl` 能装上**。

### 自查截图的做法

```bash
cd /e/妙恋畅语/app
C:/Users/GOSTAR/.workbuddy/binaries/python/versions/3.13.12/python.exe -m http.server 8110 --bind 127.0.0.1
# 另一个终端：
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new \
  --disable-gpu --enable-unsafe-swiftshader --hide-scrollbars \
  --user-data-dir="E:\\妙恋畅语\\app\\_shots\\ud_x" \
  --virtual-time-budget=14000 --window-size=1000,900 \
  --screenshot="E:\\妙恋畅语\\app\\_shots\\x.png" "http://127.0.0.1:8110/?s=panel"
```

`s=` 可取值：`welcome home panel import ocr analyzing analysis reply templates new settings me`，另加 `&b=1` 走边界场景、`&p=anran` 换对象。
