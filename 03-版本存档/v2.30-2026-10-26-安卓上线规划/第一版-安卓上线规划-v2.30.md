## 一、结论（先看这一页）

1. **「上线安卓」分三档**：装上自己手机（侧载）→ 发给朋友装（内测分发）→ 上应用商店。三档的成本差两个数量级，不是一条直线上的三个刻度。
2. **选定路线：内测先行，商店缓行。** 走完阶段 C/D 加分发改造（约 3–4 周），出一个真正能用的 apk 装进自己和朋友的手机；商店要的资质材料**并行**准备，拿到证再决定要不要走。
3. **个人身份走商店有一个实质硬点**：AI 类目要求算法备案与安全评估，实践中个人主体难以通过。所以商店档只做"材料备好、随时能走"的准备，**不做时间承诺**。
4. **两个不可逆决定必须在第一次分发前定死**：应用包名、签名密钥。见 §五 D1、D2。

## 三、三条路径，和商店那条的真实门槛

| | 侧载自用 | 内测分发 | 上国内商店 |
| --- | --- | --- | --- |
| 前置 | P1（C/D 完成） | P1 + P2 全部 | P1 + P2 + 资质审核 |
| 资质 | 无 | 无 | 软著 + App 备案 + 隐私政策（所有商店）；**AI/陪伴类目另加算法备案 + 安全评估报告** |
| 周期 | C/D 完成当天 | 再加约 1 周 | 3–6 个月，且有一关卡个人 |

商店类目问题，查证于小米开发者平台资质 FAQ（2026-01-30 更新）与网信办《人工智能拟人化互动服务管理暂行办法》（2025-12 发布）：

- 「人工智能 / 陪伴」类目要求算法备案（网信办）+ 安全评估报告 + 全国互联网安全管理服务平台审批截图。
- 本产品是"给用户自己看的分析工具"，不是"AI 陪聊"，归类上有辩护空间；**但商店从严归类是常态，最终以平台审核为准**。这条按最不利情况规划。
- 软著官方登记**免费**：中国版权保护中心自 2017-04-01 起停征软件著作权登记费（财税〔2017〕20 号）。普通办理约 60 个工作日；市面上「加急 20–30 工作日」是**代理代办的服务价（约 ¥1300）**，官方没有付费加急通道。**先走免费通道提交排队；将来真决定走商店、嫌慢时再花加急钱。**

## 六、并行线：软著申请（本周可启动，个人可办）

- 入口：中国版权保护中心 `ccopyright.com.cn`，全程在线。
- 材料四件：申请表（在线填）、**源代码前 30 页 + 后 30 页（每页 ≥50 行）**、软件说明书（操作手册）、身份证复印件。
- **一个坑提前说**：商店要求「应用名称 / 软著名称 / App 备案名称」三者一致。所以申请时软件全称必须用 App 的名字，比如「妙恋畅语软件 V1.0」——**定了就不能随手改**，要按商店口径一次写对。
- 周期与费用：**官方自办免费**（2017-04-01 起停征登记费），普通约 60 个工作日。「加急 20–30 工作日、约 ¥1300」是代理代办服务价，不是官方收费。现在走免费通道提交排队，商店路线真启动时再决定要不要加急。
- 分工：**代码页导出、说明书初稿，阿砚代备**；实名提交、签章、缴费，必须立项人本人。

## 七、商店档的完整门槛（如实记录，不做承诺）

若将来走商店，在 P1/P2/软著之外还需要：App 备案（个人可办，走云服务商接入，约 20 工作日）、各商店开发者账号实名（华为 / 小米 / OPPO / vivo / 应用宝各一个，个人可注册）、应用截图与描述素材、部分商店的安全检测。
