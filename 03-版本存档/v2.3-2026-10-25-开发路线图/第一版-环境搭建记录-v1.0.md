| 项 | 值 |

| Flutter | **3.47.8**（channel stable，revision 737ba8f885） |
| Dart | **3.13.7** |
| DevTools | 2.60.0 |

| 安装包 | `E:\dev\flutter_3.47.8.zip`（1.9G，可删，留作离线重装也行） |

**为什么装 E 盘**：C: 当时只剩 15G（已用 92%），Android Studio + SDK + 模拟器镜像要 10～12G。装 C 盘会在最后一步因为空间不足而失败——那种失败最让人崩溃，因为前面都成功了。

## 二、环境变量（用户级，已写入）

```text
PATH                      += E:\dev\flutter\bin
PUB_CACHE                  = E:\dev\pub-cache
FLUTTER_STORAGE_BASE_URL   = https://storage.flutter-io.cn
PUB_HOSTED_URL             = https://pub.flutter-io.cn
```

两个镜像变量不能省。没有它们，`pub get` 会慢到让人以为断网。

`PUB_CACHE` 同理——它默认写在 `C:\Users\<用户>\AppData\Local\Pub\Cache`，会持续撑爆 C 盘。

## 四、下次开工时先验这三条

在他自己的终端（VS Code 终端，不在沙箱里）执行：

```bat
flutter --version
flutter devices
flutter doctor
```

`flutter devices` 应该列出 `Edge (web)` 和 `Windows (desktop)`。
如果列出 Edge，说明阶段 0 通关，可以直接跑第一屏。

## 五、已知的坑（踩过或即将踩）

1. **CORS**：Flutter Web（Edge/Chrome）直连 DeepSeek API 会被浏览器拦。**阶段 0 只能验界面，验不了大模型链路。**
2. **`reg.exe` 被沙箱拦**：我这边跑 `flutter doctor` 会出现两个"崩溃"，在他自己的终端里不会有。**看到这两条崩溃不要慌，不要重装。**
3. **C 盘 15G**：任何新工具（Android Studio、模拟器镜像、Gradle）一律装 E 盘，并设 `GRADLE_USER_HOME`。
4. **首次 `flutter run` 会慢**：要编译，不是卡死。
