## 二、第 3 步要做的事

**目标一句话：粘贴一段真聊天，出来一份能指回原文的判断，和三条回复。**

### 现在真实存在的问题

1. **`Reply` 是写死的三条。** `reply.dart` 直接 `p.replies.map`，代码里根本没有"生成"这个动作，也没有加载态、失败态、超时。
2. **`analysis.dart` 的两段文案是写死的。** `alert ? '她这周主动 0 次…' : '她主动开启话题 3 次…'`，四维数字也是种子里的，不是从聊天记录算出来的。
3. **`signals` 常量表（`data.dart` 里 4 条）没有任何地方用到。** 真分析的"看到的信号"就该长在这里。
4. **`apiKey` 只在内存。** `settings.dart` 说"已保存到本机"，其实刷新就没了。第 3 步每跑一次都要重填一次，很烦——但 secure storage 是第 4 步的事，先忍。
5. **Web 版连不出去（CORS）。** 必须 `flutter run -d windows` 或 Android 真机。而 Windows 桌面要 VS 的 C++ 工具链，**本机还没装**。
6. **边界现在是写在种子数据里的人肉标记（`Person.warn`）。** 接真 API 后必须由分析结果算出来，而且**要在生成回复之前拦掉**，不能生成完再筛。

### 建议的动作顺序

1. **先把能跑网络的环境弄出来**（VS C++ 工具链，或一台 Android 真机）。没有这个，后面全是盲写。
2. `model.dart` 加两个结构：`AnalysisResult`（阶段 / 四维 / 每条依据带原文片段 / 是否检出边界）和 `ReplyDraft`（文案 / 语气 / 能不能发 / 理由）。
3. 新建 `lib/llm/deepseek.dart`：一个文件只做一件事——吃"聊天文本 + 人物信息"，吐上面两个结构。不碰界面，不引 `AppState`。
4. **先用命令行验 prompt**，别一上来就接界面。写个 `dart run tool/try_llm.dart`，把同一段样本反复调，直到输出稳定。
5. **边界硬过滤写在 Dart 里**：解析结果 → 若检出拒绝信号 → 直接把 `replies` 换成模板库里的"暂不推进"三条，整段跳过生成。这是代码里的 `if`，不是提示词里的请求。
6. 最后才动界面：`analysis.dart` / `reply.dart` 接上真数据，补加载态、失败态、超时（"没网"必须是人话，不能白屏）。
7. Key 存 secure storage 可以挪到第 4 步，别为了它卡住第 3 步。

### 验收标准

- 粘一段真聊天，点分析，出结论；**每条依据都能指回原文的某一句话**。
- 边界样本（"改天吧"）进去，出来的是"暂不推进"，**不出现任何邀约句式**。
- 断网点分析，给得出看得懂的提示，不是白屏、不是无限转圈。
- **12 屏的视觉仍然一个字没变。**

## 四、环境上的四个坑（都是实测，别再试错）

1. `flutter analyze` 在中文路径下会让 analysis server 崩（exit 255）。**一律用 `dart analyze`。**
2. **`flutter test` 会报 `Invalid WebSocket upgrade request`** ——`http_proxy` 环境变量把本机回环也代理走了。跑之前 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY`。
3. `flutter run -d edge` / `-d web-server` 在**我的执行环境**里跑不了——Flutter 要调 `reg.exe` 查 Edge 版本，而 `reg.exe` 在安全中心黑名单里。**立项人自己的终端不受影响。**
   我的替代做法：`flutter build web --release` → `python -m http.server` 起 `build/web` → Edge 无头截图自查：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new \
  --disable-gpu --enable-unsafe-swiftshader --hide-scrollbars --no-sandbox \
  --user-data-dir="E:\\妙恋畅语\\app\\_shots2\\ud_x" \
  --virtual-time-budget=14000 --window-size=1000,900 \
  --screenshot="E:\\妙恋畅语\\app\\_shots2\\x.png" "http://127.0.0.1:8121/?s=panel"
```

4. `cdn.jsdelivr.net` 在本机 TLS 握手失败；`fonts.googleapis.com` / `gstatic.com` 可通。pip 装包：tuna 镜像直接 `pip install` 会报 "versions: none"，但 **curl 下 wheel 再 `pip install --no-index 本地.whl` 能装上**。
