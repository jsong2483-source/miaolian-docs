## 二、阶段 A 做了什么（已完成，别再改回去）

**一句话：缺失值不是零分、不是低分、也不是趋势下降。**

| 改动 | 详情 |
| --- | --- |
| `Dims` / `TrendPoint` 四字段 | `int` → `int?`；`Dims.of(k)` 返回 `int?` |
| `Trend.of` | 签名改 `(int?, int?)`；任一端为空返回 `kind: 'none'`，`symbol` 为空串（角标不显示）、不出箭头、`short` 写「这次记录里没有能判断这个维度的信息」 |
| `applyAnalysisTo` | **不再用旧值兜底**。模型给 `null` 就写 `null`。四个维度各自独立，一个缺失不污染其他 |
| `applyAnalysisTo` 顺带修 | **原来从不写 `ev`**，点开维度看到的证据永远是种子数据里那句。现在写回 `evidence` + `source`；`source` 为空时给「这段记录里没有能指回去的一句原话」 |
| `createPerson` | 由 `Dims(fam: 0, heat: 0, ...)` 改为 `const Dims()`。新建的人显示 `—` 而不是 `0%`——**原来的 0 也是假的** |
| 界面安全渲染 | panel 数字 / 百分号 / 进度条 / 顶部文案 / 弹层，home 图例，折线遇空值断线（`path.moveTo` 重开） |

### 三条实现细节，改之前先看

1. **百分号要跟着数字一起消失。** `—%` 是错的，所以 `if (v != null) const Text('%')`。数字位置的宽度会窄一点，这是必要的代价。
2. **`chartCounts` 不能追加「未判断」。** 实测把「· 1 未判断」加到首页标题行，390 宽下 `RenderFlex overflowed by 27 pixels`。现在只在四个维度全部为空时换成一句「还没判断出来」。首页那行是概览，缺哪个维度到面板上直接看得到。
3. **折线遇空值断线，不是补点。** 用 `started` 标记：遇到 `null` 设 `started = false` 并 `continue`，下一个有效点 `moveTo` 重开。视觉上「线断了」正好表达「这段没数据」。末端圆点也跳过空值。

**三个改动容易被回退，记住原因：**

1. **`src/main/AndroidManifest.xml` 里的 INTERNET 权限不能删。** Flutter 模板只写在 `src/debug` 和 `src/profile`，release 包用 main——删了以后 debug 一切正常、release 装手机上所有请求静默失败。
2. **`build.gradle.kts` 里的 `ndkVersion` 是故意删的。** 本工程零原生代码，留着要下 1GB NDK。
3. **`.metadata` 里必须四条平台都在**（root / web / windows / android）。`flutter create` 会把它改写成只有 android，缺 web/windows 条目会导致 `flutter build web` 出问题。

## 六、环境上的九个坑（都是实测，别再试错）

1. `flutter analyze` 在中文路径下会让 analysis server 崩（exit 255）。**一律用 `dart analyze`。**
2. **`flutter test` 会报 `Invalid WebSocket upgrade request`** ——`http_proxy` 环境变量把本机回环也代理走了。跑之前 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY`。
3. `flutter run -d edge` / `-d web-server` 在**我的执行环境**里跑不了——Flutter 要调 `reg.exe` 查 Edge 版本，而 `reg.exe` 在安全中心黑名单里。**立项人自己的终端不受影响。**
   替代做法：`flutter build web --release` → `python -m http.server 8121` 起 `build/web` → Edge 无头截图自查：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new \
  --disable-gpu --enable-unsafe-swiftshader --hide-scrollbars --no-sandbox \
  --user-data-dir="E:\\miaolian_app\\_shots3\\ud_x" \
  --virtual-time-budget=14000 --window-size=1000,900 \
  --screenshot="E:\\miaolian_app\\_shots3\\x.png" "http://127.0.0.1:8121/?s=panel"
```

**截图参数要对上基线**：回复建议、首页、面板、导入都用 `?s=<屏名>`；**只有分析结果要带 `&b=1`**（基线文件名里写明是「分析结果-边界」）。带错参数会拍出另一屏的内容，别把它当成视觉回归失败——这轮就踩过一次。

4. `cdn.jsdelivr.net` 在本机 TLS 握手失败；`fonts.googleapis.com` / `gstatic.com` 可通。pip 装包：tuna 镜像直接 `pip install` 会报 "versions: none"，但 **curl 下 wheel 再 `pip install --no-index 本地.whl` 能装上**。
5. **`dart run` 不用配代理，反而别配。** 本机有全局 `http_proxy`，但 Dart 的 `HttpClient` 不读环境变量，直连 `api.deepseek.com` 实测能通（拿到真实 401）。
6. **改一行提示词，全部样本都要重测。** 档位边界附近的样本本来就坐在分界线上，措辞一动就翻档。提示词要尽早冻结。
7. **工程路径不能含中文——这是 AOT 的硬阻断，不是警告。** debug 走 JIT 无所谓，`flutter build apk --release` 会报 `Dart snapshot generator failed with exit code 255`。
   - `android.overridePathCheck=true` **只关 AGP 自己的检查**，救不了 AOT。
   - `mklink /J` 建 junction **也无效**，Windows 解析回真实路径，`os.getcwd()` 照样是中文。
   - 唯一解：工程放纯英文路径。现在是 `E:\miaolian_app`。
8. **release 包默认不能联网。** Flutter 模板只把 INTERNET 权限放在 `src/debug` 和 `src/profile` 的 manifest 里，**main 里没有**。已补进 `src/main/AndroidManifest.xml`。这类"debug 全好、release 静默失败"的 bug 本机验不出来，只能靠读配置发现。
9. **Android SDK 的包下不下来，`sdkmanager` 会 502。** Java 拿到的代理配置和 curl 不一样，走代理直接 `Unable to tunnel through proxy`。解决办法：从 `repository2-3.xml` 查出准确包名，用 curl 下 zip 手工铺进 `E:\dev\android-sdk`。
   另外 `unzip` 解 platform-36（11342 个文件）会被沙箱 `SIGTERM` 杀掉，**改用 Python `zipfile.extractall`**；build-tools 的压缩包顶层是 `android-16/` 而不是 `36.0.0/`，要解到临时目录再 `shutil.move`。
