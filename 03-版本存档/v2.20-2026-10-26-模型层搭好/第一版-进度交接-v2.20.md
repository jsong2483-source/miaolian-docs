## 四、环境上的五个坑（都是实测，别再试错）

1. `flutter analyze` 在中文路径下会让 analysis server 崩（exit 255）。**一律用 `dart analyze`。**
2. **`flutter test` 会报 `Invalid WebSocket upgrade request`** ——`http_proxy` 环境变量把本机回环也代理走了。跑之前 `unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY`。
3. `flutter run -d edge` / `-d web-server` 在**我的执行环境**里跑不了——Flutter 要调 `reg.exe` 查 Edge 版本，而 `reg.exe` 在安全中心黑名单里。**立项人自己的终端不受影响。**
   我的替代做法：`flutter build web --release` → `python -m http.server` 起 `build/web` → Edge 无头截图自查：

```bash
"/c/Program Files (x86)/Microsoft/Edge/Application/msedge.exe" --headless=new \
  --disable-gpu --enable-unsafe-swiftshader --hide-scrollbars --no-sandbox \
  --user-data-dir="E:\\妙恋畅语\\app\\_shots2\\ud_x" \
  --virtual-time-budget=14000 --window-size=1000,900 \
  --screenshot="E:\\妙恋畅语\\app\\_shots2\\x.png" "http://127.0.0.1:8121/?s=panel"
```

4. `cdn.jsdelivr.net` 在本机 TLS 握手失败；`fonts.googleapis.com` / `gstatic.com` 可通。pip 装包：tuna 镜像直接 `pip install` 会报 "versions: none"，但 **curl 下 wheel 再 `pip install --no-index 本地.whl` 能装上**。
5. **`dart run` 不用配代理，反而别配。** 本机有全局 `http_proxy`，但 Dart 的 `HttpClient` 不读环境变量，直连 `api.deepseek.com` 实测能通（拿到真实 401）。照搬 curl 那套去给 Dart 配代理，会把本来通的搞不通。
